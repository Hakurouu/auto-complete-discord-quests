# auto-complete-discord-quests
How to Use

1. Open **Discord** on your desktop app or browser.
2. Go to the **Quests** tab, and accept all the quests you want to complete (Quest on Desktop for those that need it).
3. Press **`Ctrl` + `Shift` + `I`** (or `Cmd` + `Option` + `I` on Mac) to open Developer Tools.
4. Click on the **Console** tab at the top.
5. Copy the entire script from `script.js` (or below).
6. Paste it into the Console and press **Enter**. (If you haven't used the console before, you will have to type `Allow pasting` into the console first before pasting the script.)
